Institute Ledger — تبدیلیاں (Data/Login Safety RC)

اس ریلیز میں موجودہ سورس کی جانچ کے بعد محدود تبدیلیاں کی گئیں:

1. منتخب ڈیٹا بیس کا راستہ انسٹالیشن فولڈر سے باہر APPDATA میں محفوظ رہتا ہے۔
2. محفوظ شدہ ڈیٹا بیس موجود ہو تو پہلے اسے read-only integrity/schema check سے گزارا جاتا ہے؛ غائب/خراب فائل پر خاموش نیا ڈیٹا بیس نہیں کھولا جاتا۔
3. پہلی بار ڈیٹا فولڈر کا انتخاب واضح طور پر کیا جاتا ہے؛ نیا خالی ڈیٹا بیس صرف صارف کی واضح منظوری پر بنتا ہے۔
4. موجودہ ریکارڈز مگر Admin کے بغیر ڈیٹا بیس میں نیا Admin خودکار طور پر بنانے سے پہلے پروگرام رک کر اصل ڈیٹا بیس/بیک اپ منتخب کرنے کا پیغام دیتا ہے۔
5. لاگ اِن پر Admin (پہلی ترجیح) یا Teacher منتخب کیا جا سکتا ہے؛ موجودہ PBKDF2-SHA256/260000 ہیش تصدیق برقرار ہے۔ Student لاگ اِن کی اجازت نہیں؛ پرانے Student ریکارڈز حذف نہیں کیے جاتے۔
6. لاگ اِن اسکرین سے موجودہ DB یا بیک اپ منتخب کرنے کا راستہ شامل ہے۔ .bak/.sqlite/.sqlite3 فائل کو براہ راست live DB کے طور پر کھولنے کے بجائے نئے منتخب data folder میں SQLite backup API کے ذریعے کاپی کیا جاتا ہے؛ اصل فائل نہیں بدلی جاتی۔
7. پہلی Admin تخلیق اور Teacher login بنانے کے فارم میں Password/Confirm Password کے Show/Hide کنٹرول، password match اور 12+ حرف کی شرط شامل ہے۔
8. DB میں institute_id setting محفوظ کرنے کی شروعات کی گئی ہے؛ یہ UUID نئی settings میں بنتا ہے اور موجودہ DB میں موجود value INSERT OR IGNORE کی وجہ سے برقرار رہتی ہے۔

احتیاط:
- یہ Release Candidate ہے، حتمی Windows installer نہیں۔
- Windows GUI، حقیقی موجودہ صارف DB، installer، x86/x64 binaries اور Inno Setup کی عملی جانچ اس ماحول میں نہیں ہوئی۔
- بیک اپ میں SQLite database کی مکمل transactional copy شامل ہوتی ہے۔ بیرونی logo/image files کی bundle/restore مکمل طور پر ثابت نہیں؛ اگر ان کے paths ڈیٹا بیس سے باہر ہوں تو انہیں الگ محفوظ رکھیں۔
- اصل DB استعمال کرنے سے پہلے اس کی الگ نقل/بیک اپ بنائیں۔

- عام ttk.Button، Accent، Navigation، Attendance Status اور Calendar Buttons پر اسی wallpaper سے تیار کردہ blended image surface لگائی؛ legacy tk.Button پر بھی cached image surface اور hover/pressed states ہیں۔ native Tk میں per-pixel alpha transparency دستیاب نہیں، اس لیے visual blend استعمال ہوتا ہے۔
