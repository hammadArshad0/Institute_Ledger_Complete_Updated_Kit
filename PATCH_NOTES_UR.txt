Institute Ledger — اس ریویژن میں کی گئی محدود تبدیلیاں

- Removed public Create Account action from login screen; login remains available.
- Blocked authentication for legacy student accounts without deleting their database rows.
- Disabled public self-registration; teacher accounts remain admin-managed inside the app.
- Restricted Admin > Login Accounts creation to teacher accounts and raised password minimum to 12 characters; legacy student rows remain untouched.
- Main-window close now destroys direct child Toplevel windows before backup and database close.

اہم: اصل ڈیٹا بیس میں کوئی تبدیلی نہیں کی گئی۔ پرانے student user rows حذف نہیں کیے گئے، مگر student login بند ہے۔ Windows GUI/installer کے عملی ٹیسٹ ابھی باقی ہیں۔
- طالب علم شامل کرنے یا پروفائل میں طالب علم لاگ اِن بنانے کے راستے بھی بند کیے؛ صرف ایڈمن کے ذریعے استاد کا اکاؤنٹ بن سکتا ہے۔

- لاگ اِن اور پرانا ڈیٹا/بیک اپ کھولنے کے بٹن الگ برابر چوڑائی والے خانوں میں رکھے؛ بٹنوں کی عمودی جگہ کم کی تاکہ وہ آپس میں نہ ملیں۔
- ادارے کا لوگو Settings میں Choose & crop اور Adjust کے ذریعے تبدیل/فریم کیا جا سکتا ہے؛ اس فیچر کو برقرار رکھا۔
- سورس کی Python syntax compilation کامیاب۔ Windows پر GUI اور EXE installer کے حقیقی ٹیسٹ اس ماحول میں نہیں کیے گئے۔

- v8: لاگ اِن اسکرین کی عمودی جگہ بہتر کی: کارڈ کی دستیاب اونچائی بڑھائی، سرخیوں/فیلڈز کے درمیان فاصلہ کم کیا، ان پٹ فیلڈز قدرے مختصر کیے، اور لوگو پینل چھوٹا کیا تاکہ نیچے کے دونوں ایکشن بٹن کٹنے کا امکان کم ہو۔ Python syntax compilation کامیاب؛ Windows پر بصری/عملی تصدیق ابھی باقی ہے۔


ورژن 10 — پہلی تنصیب پر Admin اکاؤنٹ کا مسئلہ
- انسٹالر اب first_install.flag شامل کرتا ہے۔ پہلی بار ایپ کھلنے پر پرانا محفوظ DB path خاموشی سے استعمال نہیں ہوگا۔
- صارف واضح طور پر پرانی ڈیٹابیس منتخب کر سکتا ہے، یا NO منتخب کر کے نیا ڈیٹا فولڈر بنا سکتا ہے۔
- نئے خالی ڈیٹابیس پر موجودہ first_admin_exists شرط کے مطابق Create Admin Account اسکرین کھلے گی۔

- پہلی تنصیب کا نشان صرف درست ڈیٹابیس منتخب ہونے کے بعد ختم ہوتا ہے؛ منسوخی پر اگلی بار انتخاب دوبارہ آئے گا۔

- Tk/Xvfb پر Dashboard، Students، Teachers، Fees، Timetable، Attendance، Progress، Accounts، Graphs، Reports اور Settings کے smoke tests کامیاب؛ Windows installer کا حقیقی ٹیسٹ اس ماحول میں نہیں کیا گیا۔
